# 雙人爆笑故事劇場《愚公移山》售票網站

這是一個一頁式的靜態售票網頁，包含前端票價試算器，以及連動 Google 表單的功能。

## 專案結構
- `index.html`: 網站主結構與內容
- `style.css`: 網站視覺樣式 (行動裝置優先設計)
- `app.js`: 票價試算器與表單跳轉互動邏輯
- `圖片/`: 包含海報與人物去背圖片等靜態素材

## 部署說明
本網站為純靜態網頁 (HTML/CSS/JS)，無需任何建置步驟 (Build step)。可以直接部署到支援靜態網頁託管的服務，例如 **Zeabur**、**GitHub Pages** 或 **Vercel**。

在 Zeabur 上部署時，Zeabur 會自動偵測到根目錄下的 `index.html`，並將其識別為 Static HTML 專案進行部署。
